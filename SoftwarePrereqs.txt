5. Local Installation and Startup
---------------------------------

A. Obtain the source code

Public GitHub mirror:

    https://github.com/Max-pgs/life-ledger-render

Clone with Git:

    git clone https://github.com/Max-pgs/life-ledger-render.git
    cd life-ledger-render-main

Alternatively, download the repository as a ZIP file and extract it.


B. Configure the local backend environment

The repository contains a root .env.example file.

Windows PowerShell:

    Copy-Item .env.example .env

macOS / Linux:

    cp .env.example .env


C. Start PostgreSQL and the Django backend

Ensure Docker Desktop is running.

From the project root:

    docker compose up --build

The Docker configuration starts the PostgreSQL database and Django backend.
Database migrations are applied automatically when the backend container starts.

The backend API runs on port 8000 and is used by the React frontend.
The root backend URL is not a user-facing page.

Optional Django admin interface:

    http://localhost:8000/admin/

If a local administrator account is required:

    docker compose exec backend python manage.py createsuperuser


D. Start the React frontend

Open a second terminal:

    cd life-ledger-render-main
    cd frontend
    npm install
    npm run dev

The frontend normally runs at:

    http://localhost:5173

Open this address in a browser to use Life Ledger locally.

The frontend falls back to the local API address:

    http://127.0.0.1:8000/api

A frontend .env file is therefore not required for the standard local setup.
If a different API endpoint is required, frontend/.env.example can be copied to frontend/.env
and VITE_API_BASE_URL can be changed.

Optional: Django Admin
The Django admin interface is available locally at:

http://localhost:8000/admin/
If no local administrator account exists, open a new terminal, and create one from the project root:

cd life-ledger-render-main
docker compose exec backend python manage.py createsuperuser
Follow the prompts to create the administrator account, then use the created credentials to sign in to the Django admin interface.

The admin interface can be used to manage application data such as commitment groups, templates and guidance content.

7. Production Deployment Information
------------------------------------

The submitted render.yaml defines the Render deployment.

Backend:
    Python 3.11.9 on Render
    Build command: bash build.sh
    Pre-deploy command: python manage.py migrate
    Start command: gunicorn config.wsgi:application --bind 0.0.0.0:$PORT

Frontend:
    Static Render service
    Build command: npm ci && npm run build
    Output directory: frontend/dist

Database:
    Render PostgreSQL
