Life Ledger
CodeList.txt

Purpose
-------
This file provides the concise code-module listing requested for the MSc IT+ submission package.
It identifies key significant files developed for Life Ledger and summarises the level of AI involvement.
A more detailed file-by-file AI contribution register, including assistance dates and inline source markers,
is provided separately in AI_DECLARATION.md.

Classification
--------------
Predominantly user written
    No direct AI-generated code was used for the listed file or area.

AI-assisted
    AI was used for guidance, debugging, implementation support, or selected code sections.
    The final code was reviewed, adapted and tested.

Significant AI assistance
    AI contributed substantially to the implementation of the file or a major part of it.
    The resulting code was reviewed, revised where necessary and tested.
